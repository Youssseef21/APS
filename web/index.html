Occupation des caches

Taux de remplissage par cache (%)

Mo utilises / capacite X. Une barre a 100 % = cache plein.

Temps gagne par cache

Millisecondes attribuees au cache le plus rapide. Seul ce cache compte pour le score.

Duplication : copies par video

1 = une seule copie. 2+ = video reproduite dans plusieurs caches.

Combien de videos ont k copies

Barre k=1 : videos uniques. k=2, 3… : videos dupliquees.

Volume de donnees par endpoint (DC vs caches)

Gris = datacenter. Couleurs = cache qui sert vraiment (copie la plus rapide).

Presence video × cache

Ligne = cache, colonne = video. Case bleue = presente. Plusieurs cases sur une colonne = duplication.
